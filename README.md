# 🎨 Flux Theme

A carefully crafted theme for Visual Studio Code —  
focused on clarity, contrast, and long coding sessions.

Minimal. Consistent. Eye-friendly.

---

## ✨ Features

- 🎯 Clean and balanced color palette
- 🌙 Full dark theme support
- ☀️ Light theme variant included
- 🧠 Designed for long coding sessions (reduced eye strain)
- 🎨 Consistent syntax highlighting across languages
- 💡 Carefully tuned UI colors (panels, tabs, activity bar)
- ⚡ High contrast where it matters (focus states, selections)

---

## 🧠 Design Philosophy

Flux Theme is built around a few core principles:

- **Readability first** — code should be easy to scan
- **Low noise** — avoid unnecessary visual clutter
- **Consistent semantics** — colors mean the same thing everywhere
- **Focus-driven UI** — important elements stand out naturally

No random colors.  
No visual overload.  
Everything has a purpose.

## 🎨 Themes Included

- **Flux Dark** — optimized for night coding
- **Flux Light** — clean and bright for daytime use

Both themes share the same color logic for consistency.

## ⚙️ Customization

The theme is designed to work out of the box,  
but you can tweak it via VS Code settings if needed:

```json
"workbench.colorCustomizations": {
  "activityBar.activeBorder": "#39FF14"
}

```

Example:

Neon green accents for active elements
Subtle UI contrast for better focus

## 📦 Installation

**Install from VSIX**

1. Download the latest .vsix file from GitHub Releases
2. Open VS Code
3. Go to Extensions
4. lick the ... menu
5. Select Install from VSIX...
6. Choose the file

Or via terminal:

```bash
code --install-extension flux-theme-x.x.x.vsix
```

## 🚀 Usage

1. Open Command Palette (Ctrl + Shift + P)
2. Run: `Preferences: Color Theme`
3. Select:

- **Flux Dark** or
- **Flux Light**

## 🔒 Privacy

Flux Theme:

- Does not collect any data
- Does not include telemetry
- Does not run background processes
- Does not interact with external services

Purely visual. Fully local.
